# Taller de Introducción a GitHub Copilot

## Repositorio de demostración para GitHub Copilot

¡Bienvenido a nuestro taller sobre GitHub Copilot! Esta herramienta impulsada por IA está diseñada para ayudarte a escribir código sugiriendo líneas o bloques de código mientras escribes. Es como tener un compañero de programación en pareja que puede ayudarte a navegar a través de tu viaje de codificación.

---

> [!IMPORTANT]
> Las instrucciones de los laboratorios se pueden encontrar [aquí](labs).

---

> [!NOTE]
> 1. **Respuestas Diversas**: Es importante señalar que GitHub Copilot genera respuestas basadas en los prompts dados por el usuario. Sin embargo, las respuestas pueden variar para cada participante, incluso si las instrucciones son las mismas. Esto se debe a los algoritmos subyacentes de GitHub Copilot, que utilizan modelos de aprendizaje automático entrenados en una amplia gama de repositorios de código público. El modelo genera sugerencias basadas en patrones y estructuras que ha aprendido, lo que puede llevar a diferentes salidas para diferentes usuarios.
> 2. **Desafío de Precisión**: Aunque GitHub Copilot es una herramienta poderosa, no es infalible. Las respuestas que genera a veces pueden ser incorrectas o no exactamente lo que pretendías. Esto es parte del desafío y la experiencia de aprendizaje. Durante el taller, te animamos a experimentar modificando tus prompts para guiar a GitHub Copilot hacia la generación del código correcto.
> 3. Recuerda, GitHub Copilot es una herramienta diseñada para ayudarte, pero no reemplaza la necesidad de una comprensión profunda de tu código y prácticas regulares de prueba y depuración. ¡Esperamos explorar esta emocionante herramienta contigo durante el taller!

---

> [!CAUTION]
> Para garantizar una configuración consistente y sin problemas para todos, **se requiere que todos los participantes usen GitHub Codespaces para las porciones prácticas de este taller**. Esto garantiza que todos tengan el mismo entorno de desarrollo, configuración y herramientas, independientemente de su máquina local.
> No recomendamos usar entornos de desarrollo locales para este taller, ya que no se brindará soporte para solucionar problemas de configuración local. Por favor, asegúrate de tener acceso a GitHub Codespaces antes de que comience el taller.
